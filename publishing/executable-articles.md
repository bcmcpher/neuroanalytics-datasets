# Executable Articles

An executable article ships its own computational environment: the figures are regenerated
from the data when the article is built, rather than pasted in as images. If it builds, the
results are reproducible — that is the whole claim, and it is checkable rather than
asserted.

**NeuroLibre** is the neuroscience-specific preprint server for these, built on Jupyter
Book — the same technology this book is written in, so the authoring workflow will already
be familiar to anyone who has contributed here.
